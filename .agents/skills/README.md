## How to add a skill

Copy from [OKHP3/skillz](https://github.com/OKHP3/skillz) to this project:

```bash
# From your local machine (requires skillz cloned to ~/.agents/skills)
cp -r ~/.agents/skills/{category}/{skill-name} .agents/skills/
git add .agents/skills/{skill-name}
git commit -m "feat: add {skill-name} from skillz/{category}"
git push origin main
```

The catalog table above regenerates automatically via GitHub Actions on push.

## How to remove a skill

```bash
git rm -r .agents/skills/{skill-name}
git commit -m "feat: remove {skill-name} — reason: {why}"
git push origin main
```

## How to update a skill version

```bash
cp -r ~/.agents/skills/{category}/{skill-name} .agents/skills/
git add .agents/skills/{skill-name}
git commit -m "chore: update {skill-name} to v{version}"
```

## Skill discovery path

Agents discover skills by scanning `.agents/skills/` from the project root.
This works automatically in Replit (project is cloned), VS Code (when open at project root),
and any other compliant agent client (Claude Code, Copilot, Codex, Cursor, Gemini CLI).

`skillz` (the library) is the source of truth. This directory is the deployed copy.
