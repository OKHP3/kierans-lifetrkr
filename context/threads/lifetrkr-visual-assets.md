## Decisions and rationale

### Retained direction

1. **Move from moodboard to production package.** The user explicitly asked for individual images rather than a unified collage. Each deliverable should therefore be generated, exported, reviewed, and stored independently.
2. **Use mystical warmth in service of self-development.** The revised direction keeps moonlight, candles, crystals, jewel tones, and a magical cat, but the dominant narrative is a reflective life OS: journaling, planning, tracking, and growth.

4. **Favor variation within a shared system.** Assets should share color, light, motif, and emotional tone without repeating one composition or forcing all concepts into one collage.

## Reusable methods and assets

### Visual-pillar framework

Use the following six pillars as a checklist for every new asset:

- Whimsigoth: jewel tones, moonlight, velvet, candlelight, and an understated magical quality.
- Dark academia: books, journals, libraries, thoughtful study, aged paper, and quiet intellectual warmth.
- Jewel-tone cottagecore: plants, botanical borders, cozy domestic details, and saturated but harmonious color.
- Personal growth: visual cues for reflection, progress, planning, and becoming—not fantasy for its own sake.
- Self-reflection: journals, constellations, moon phases, windows, contemplative poses, and open negative space.
- Black-cat companion: friendly, curious, slightly magical, recognizable, and consistent across assets.

### Anti-pattern filter

Before approving an image, ask: Is it so dark that details disappear? Does it look like a crystal-shop advertisement? Is it overtly occult or threatening? Is it a collage when a standalone asset was requested? Does it communicate fantasy more strongly than journaling, tracking, reflection, or growth? Does it use a different cat, palette, or visual language without a deliberate reason? A “yes” answer is a review flag.

### Asset brief library

1. **Primary app icon — square 1024×1024.** Black cat with amethyst eyes, a crescent-moon halo, and plum, violet, emerald, and sapphire jewel tones. Keep text minimal or absent. Optimize for app-store icon, GitHub repository icon, and favicon-source use. The essential test is recognition at small sizes.
2. **Alternate app icon — square.** Use a cat silhouette, crystal starburst, modern flat treatment, and less illustration. Target Android adaptive-icon use and a more compact, contemporary reading.
3. **Hero banner — 1920×1080.** Show a black cat on stacked journals in front of a moonlit library window with hanging plants, crystals, and warm candlelight. Proposed text: “Kieran's LifeTrkr” and “Track • Reflect • Grow.” Target GitHub social preview and website-hero use. Text legibility must be checked separately from the artwork.
4. **Mobile wallpaper — 1290×2796.** No text. Include a black cat, moon, mountains, journal, and stars. Compose vertically for splash-screen and mobile-background use, with safe space around system overlays.
5. **Dashboard background — landscape.** Keep it subtle and low contrast: gold stars, hanging crystals, vines, and a deep-plum atmosphere. It must sit behind charts and habit-tracker content without reducing readability or making interactive elements compete with the background.
6. **Journal cover — illustrated notebook cover.** Title: “LifeTrkr Journal.” Include cat, moon, books, and a botanical border. It should feel like a tangible reflective object, not a spellbook prop.
7. **Character mascot — full-body portrait.** Friendly, curious, and slightly magical black cat. Candidate names in the source: Nyx, Salem, Jinx, Opal, and Juniper. Establish consistent markings, eyes, posture, and silhouette before reusing the character.
8. **Loading screen — portrait.** Cat looking up at constellations with minimal text. Use generous negative space and a calm reading during loading; avoid dense detail that becomes visual noise on a small phone.
9. **Desktop banner — wide format.** Artwork only, no UI. Intended for website headers, Discord server banner, and GitHub README header use. Keep key subject matter within a safe central crop so multiple banner dimensions remain usable.
10. **Brand style board — separate reference sheet.** Include the approved color system, type choices, style ratio, motif examples, cat guidance, and do/don't examples. This is a design reference deliverable, not a production UI background.
